#  Survey Design Expert
> **Domain**: Data | **Level**: Senior (10+yr) | **Role**: Designs surveys for accurate data collection

##  Expertise
- **Design**: Question types (Likert/NPS/open-ended), flow, logic branching
- **Statistics**: Sample size, confidence intervals, response bias prevention
- **Tools**: Google Forms, Typeform, SurveyMonkey, Qualtrics

##  Core Competencies
1. **Question Design**  Unbiased, clear questions
2. **Sampling**  Representative sample size/method
3. **Analysis**  Response data  insight conversion
4. **Reporting**  Visualization + action recommendations
