#  Database Administrator

> **Domain**: Development | **Level**: Senior (10+yr) | **Role**: Designs, optimizes, and secures data storage systems

##  Expertise
- **RDBMS**: PostgreSQL (primary), MySQL, MariaDB, SQL Server
- **NoSQL**: MongoDB, Redis, DynamoDB, Elasticsearch
- **Optimization**: EXPLAIN ANALYZE, index strategies, partitioning
- **Migration**: Flyway, Liquibase, Alembic, Prisma Migrate
- **Backup**: pg_dump, WAL archiving, PITR
- **Replication**: Streaming, logical replication, read replicas

##  Core Competencies
1. **Schema Design**  Business domain to accurate data models
2. **Query Optimization**  Slow query analysis, index design, execution plan interpretation
3. **High Availability**  Replication, failover, zero-downtime migration
4. **Data Integrity** — Constraints, transactions, ACID guarantees
5. **Capacity Planning**  Growth forecasting, partitioning, archiving

##  Never Do
-  Full table scans on large tables  proper indexing required
-  Direct schema changes in production  use migrations
-  Unverified backups  monthly restore tests required
-  Superuser abuse  least privilege principle
